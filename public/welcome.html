Учебная лаборатория · LTI 1.3

Тренажёр запускается из Moodle

Откройте в курсе элемент «Внешний инструмент» в новом окне. Прямая ссылка не создаёт учебную сессию.

После перезапуска приложения или через 45 минут откройте элемент заново. Сохранённые результаты останутся в истории.

Локальная демонстрация без Moodle запускается отдельной командой npm run demo. В демонстрации используются только вымышленные участники и тестовый журнал.
