# Три задания по RAG-рекомендательной системе интернет-магазина

Тема: понимание подхода RAG, векторного представления запроса и выбора актуального источника данных магазина. Формат — короткий ответ. Идентификаторы и веса соответствуют лабораторной: `q1` — 3, `q2` — 3, `q3` — 4 балла; всего 10.

## q1 — Подход к генерации ответа, 3 балла

Ассистент интернет-магазина сначала извлекает релевантные фрагменты описаний товаров из базы знаний, затем передаёт их языковой модели для генерации ответа покупателю. Как называется этот подход? Введите общепринятую аббревиатуру из трёх латинских букв.

Правильный ответ: **RAG**. Серверный эталон: `rag`.

Обоснование: Retrieval-Augmented Generation объединяет извлечение информации и генерацию ответа с опорой на извлечённые сведения. См. [Lewis et al., Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401).

## q2 — Векторное представление, 3 балла

Для семантического поиска модель преобразует запрос покупателя в плотный числовой вектор, который сравнивается с векторами фрагментов базы знаний. Как называется такое векторное представление? Введите английский термин в единственном числе.

Правильный ответ: **embedding**. Серверный эталон: `embedding`.

Обоснование: embedding — векторное представление; в описанном варианте семантического поиска запрос и фрагменты представлены в общем векторном пространстве. См. [Sentence Transformers: Semantic Search](https://www.sbert.net/examples/sentence_transformer/applications/semantic-search/README.html).

## q3 — Актуальность цены и наличия, 4 балла

Перед рекомендацией товара нужно подтвердить его текущую цену и наличие. Доступны три источника: LLM — память языковой модели; INDEX — векторный индекс, обновлённый вчера; API — ответ информационной системы магазина с ценой и остатком на текущий момент. Какой источник следует использовать для этой проверки? Введите одно обозначение: LLM, INDEX или API.

Правильный ответ: **API**. Серверный эталон: `api`.

Обоснование: по условию именно ответ API содержит текущие значения цены и остатка. Вчерашний индекс может содержать устаревшие сведения; память модели не подтверждает состояние конкретного магазина. Задание проверяет применение требования актуальности данных из темы НИР.

## Правила проверки

- Принимается ровно одна строка для каждого из `q1`, `q2`, `q3`.
- Пробелы по краям удаляются, регистр игнорируется: `RAG` и `rag` равнозначны.
- Синонимы, перевод, кавычки, точка в конце и другие добавления автоматически не удаляются. Например, `эмбеддинг` и `embeddings` не соответствуют заданному формату q2.
- За верный ответ начисляется полный вес вопроса, за неверный или пустой — 0. Частичный итог возникает при правильном ответе только на часть вопросов.
- Отсутствующий ключ, лишнее поле, нестроковое значение или ответ длиннее 200 символов отклоняются как некорректный ввод. HTTP-обработчик возвращает 400 и не отправляет оценку в Moodle; это проверено автоматическими тестами и живым локальным протоколом.
- Проверка выполняется серверной функцией `grade`. Для передачи формулировок в браузер предусмотрена `getPublicTasks`, которая не включает эталонные ответы.
